# PPTMaster 设计系统

本技能只负责 **视觉决策**。叙事由叙事技能负责，工具操作由执行技能负责，审计/截图由验收技能负责；本技能不调用 `ppt_*` 工具，也不修改 deck。

## 硬纪律

| 纪律 | 治什么 |
|---|---|
| **全局锁一套 design token，单一强调色全程不换** | 配色跳变（橙突然变蓝） |
| **版式跟内容走，但吸附登记版式骨架，不自由发明** | 黑块遮挡 / 元素乱叠 |
| **几何图形里不写可见文字** | 坐标轴/图表文字翻转 |
| **内置简洁版式（封面/章节/要点/两栏/大数字/引用/结尾）视为登记版式** | 避免临时发明未登记结构 |
| **反 AI slop**：无渐变、无 emoji 图标、无圆角卡片+左 border 套路、无 SVG 人像 | 一眼 AI、掉档 |

## 流程

1. **锁 token**：从客户 VI 取色；没有就从预设主题选一套。写死 `{accent, ink, paper, font_sans, grid:12}`，全 deck 引用；不从记忆猜品牌色。
2. **选版式**：数据→大数字/矩阵/条形；流程→时间线/循环；对比→左右对照；并列判断→等权卡片；结论→大字 statement。每页从登记版式选，不临时发明。
3. **排版**：12 列网格、左对齐贴近内容轴；中文大标题按字数分档防溢出；主标题:正文字号 ≥ 8:1。
4. **反 slop**：每个元素必须挣得位置；真图未就位用诚实 placeholder，不硬凑丑 SVG；同一张图不重复。

## 输出

输出 **design token + 版式选择 + 排版约束**，交给成稿/执行技能落地。不要在本技能内改 deck，也不要把审计结论当成设计决策。

详细规则：`references/design-tokens.md`、`references/layout-system.md`、`references/anti-ai-slop.md`。
