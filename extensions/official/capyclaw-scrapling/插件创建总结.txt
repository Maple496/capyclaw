🔧 技术架构
-----------

1. DSH 插件系统
   - 基于 Cordis 依赖注入框架
   - 双半架构：宿主半（Node.js）+ 浏览器半（Web）
   - 通过 cordis.patch.yml 配置加载

2. 宿主半（lib/host.mjs）
   - 实现 Cordis 插件接口：name 和 apply
   - 通过 ctx.provide() 注册服务
   - 管理 Scrapling Python 进程调用

3. 浏览器半（client/client.js）
   - 使用 __ModuleLoader__ 加载
   - 可以注册 UI 组件、命令等
   - 通过 ctx.slots 注入界面元素

4. Bundle 配置（cordis.patch.yml）
   - 定义插件 ID 和配置
   - 在 DSH 启动时由 bundle 系统加载

📚 使用方法
-----------

### 在其他插件中使用 Scrapling 服务

```javascript
// 在你的插件中声明依赖
export const inject = ['scrapling']

export async function apply(ctx) {
  // HTTP 抓取
  const result = await ctx.scrapling.fetch('https://example.com')
  
  // 浏览器模式
  const page = await ctx.scrapling.fetchWithBrowser('https://example.com', {
    waitFor: '.content'
  })
  
  // 解析 HTML
  const doc = ctx.scrapling.parse(result.html)
  const titles = doc.css('h1::text')
}
```

### DSH Package.json 配置

```json
{
  "name": "dsh-scrapling",
  "dsh": {
    "category": "tool",           // 工具类插件
    "platform": "both",           // 服务器和浏览器都支持
    "client": {
      "platform": "web",          // 客户端在 Web 平台
      "immediately": false        // 非立即加载
    }
  }
}
```

🔍 API 接口
-----------

### ctx.scrapling.fetch(url, options)
HTTP 模式抓取页面

参数:
- url: string - 目标 URL
- options: object - 可选配置
  - headers: object - 自定义请求头
  - proxy: string - 代理地址
  - timeout: number - 超时时间（毫秒）

返回: Promise<{ url, html, status }>

### ctx.scrapling.fetchWithBrowser(url, options)
浏览器模式抓取页面

参数:
- url: string - 目标 URL
- options: object - 可选配置
  - waitFor: string - 等待的选择器
  - timeout: number - 超时时间
  - screenshot: boolean - 是否截图

返回: Promise<{ url, html, screenshot? }>

### ctx.scrapling.parse(html)
解析 HTML 内容

参数:
- html: string - HTML 字符串

返回: ParsedDocument - 包含 css() 和 xpath() 方法

### 添加实际的 Python 调用

目前 host.mjs 中的实现是存根（stub），需要实现实际的 Python 调用：

方式 1: 子进程调用
```javascript
import { spawn } from 'node:child_process'

async function callScrapling(command, args) {
  return new Promise((resolve, reject) => {
    const proc = spawn('python', ['-m', 'scrapling', ...args])
    let output = ''
    proc.stdout.on('data', data => output += data)
    proc.on('close', code => {
      if (code === 0) resolve(JSON.parse(output))
      else reject(new Error('Scrapling failed'))
    })
  })
}
```

方式 2: HTTP API
```javascript
async function callScraplingAPI(endpoint, data) {
  const response = await fetch(`http://localhost:8000/api/${endpoint}`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(data)
  })
  return response.json()
}
```

方式 3: MCP Server
利用 Scrapling 的 MCP Server 功能，通过 stdio 通信
