    用选择器把数据取出来

    CSS 选择器告诉 DSH 要抓页面里的哪些数据；::text 取文字、::attr(名) 取属性。点演示目标会自动配好示例。

    常用写法：.price::text（类名 price 的文字）· a::attr(href)（所有链接地址）· table.summary tr td:nth-child(2)::text（表格第 2 列）

    能力说明（诚实边界）
    
          
    本工具当前版本的能力与边界，如实告知：
    
        
    
      
    
      
      
        
    • ✅ HTTP 抓取：直连目标网址获取页面内容，支持重定向跟随与超时控制。
      • 
        
    • ✅ CSS 选择器提取：纯 Node 实现（无外部依赖），支持 ::text、::attr()、组合器与常见伪类。
      • 
        
    • ✅ 数据导出：JSON / CSV，可复制或下载。
      • 
        
    • 🔒 浏览器渲染：未实现。需要外部 Python scrapling 运行时（隐身浏览器 / Cloudflare 绕过 / JS 渲染），界面上已锁定，不会假装可用。
      • 
        
    • 🔒 XPath：未实现，同样如实标注。
      • 
        
    • 🏠 本服务只监听 127.0.0.1，不会暴露到外网。
