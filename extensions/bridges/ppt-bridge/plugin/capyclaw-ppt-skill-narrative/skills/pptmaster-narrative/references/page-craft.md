# 切页与页面文案

## 一页一观点

1. 把一章的核心判断列出来，每个独立判断一页。
2. 每页配 ≤4 条论据；超过 4 条 = 两个观点，拆页。
3. 每条论据挂 `evidence_refs`；无出处的判断标假设或砍掉。
4. 与本页判断无关的论据，再有趣也不放。

## 判断句标题

- ❌ 话题词：“品牌定位”“竞品分析”“市场现状”
- ✅ 判断句：“竞品在高质平价与匠人叙事间留下中间带”“增长正从开店红利切到复购红利”

标题就是这页的结论；读者扫标题应能获得论证主线。

## 文案公式

| 页型 | 公式 |
|---|---|
| 问题/痛点 | PAS：痛点 → 代价 → 方案 |
| 紧迫 | Cost of Inaction：不行动每周期损失什么 |
| 转变 | Before-After-Bridge：之前 → 之后 → 方案是桥 |
| 优势 | FAB：能力 → 优势 → 利益 |
| 对比 | 前后对比：痛点 vs 效果，感性 + 理性 |

## 情绪弧

好奇 → 焦虑/不满（摆冲突）→ 希望（给方向）→ 信任（证据）→ 笃定/紧迫（行动）。

避免“首先/其次/最后”“综上所述”“赋能/抓手/闭环”等 AI 味套话；用具体细节和数字。
