# dsh-scrapling 快速入门

## 📦 这是什么？

DeepSeek Harness (DSH) 的网页数据爬取插件。它有两部分：

1. **scrapling 服务** —— 给其他插件用的抓取 API（`fetch` + `parse` 选择器提取）
2. **爬虫工作台** —— 一个给普通人用的网页界面，看得见 DSH 是怎么把数据爬下来的

## 🚀 1 分钟开始

```bash
cd extensions/official/capyclaw-scrapling

# 启动工作台
node server/server.mjs
# → [dsh-scrapling] 工作台已就绪: http://127.0.0.1:39640/ （浏览器打开即用）
```

浏览器打开 **http://127.0.0.1:39640/**，然后：

1. **点一个演示目标**（比如「📚 每日名言」）—— 网址和选择器都自动配好
2. **点「开始爬取」** —— 看 DSH 一步步把数据爬下来（每步真实耗时）
3. **拿到数据** —— 表格 / JSON 视图，一键导出 CSV（Excel 可开）或 JSON

内置三个演示页（名言 / 商品 / 新闻）**不需要外网**；也可以输入任意真实网址（如 `https://quotes.toscrape.com/`）。

## 💡 选择器 30 秒入门

| 想要什么 | 怎么写 |
|---|---|
| 某类元素的文字 | `.price::text` |
| 所有链接地址 | `a::attr(href)` |
| 表格第 2 列 | `table tr td:nth-child(2)::text` |
| 列表项里的标题 | `.item h2::text` |

两个冒号 `::text` 取文字、`::attr(名)` 取属性，其余写法和浏览器里一样。

## 🔌 在插件代码里用

```javascript
export const inject = ['scrapling']

export async function apply(ctx) {
  const page = await ctx.scrapling.fetch('https://quotes.toscrape.com/')
  const doc = ctx.scrapling.parse(page.html)
  const quotes = doc.css('.quote .text::text')   // Scrapy 语义
}
```

## ⚙️ 配置

环境变量或 `cordis.patch.yml`：`DSH_SCRAPLING_PORT`（默认 39640）、`DSH_SCRAPLING_TIMEOUT_MS`（默认 20000）、`DSH_SCRAPLING_WORKBENCH`（默认 true）。
