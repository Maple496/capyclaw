# SCQA 与金字塔

## SCQA

- **S 现状**：对方认可的事实。
- **C 冲突**：变化/矛盾/威胁，让现状不可持续。
- **Q 问题**：因此必须回答的那一个核心问题（根问题）。
- **A 答案**：你的顶层主张，后面所有章节为它服务。

S+C+Q 落进 `brief_opening`；A 落进 `conclusion.governing_thought`，并在开场预告。

## 金字塔

```text
顶层结论 A
  ├─ 论点 1（章节 1）
  │    ├─ 论据（页）
  │    └─ 论据（页）
  ├─ 论点 2
  └─ 论点 3
```

- 章节 3–5 个；把章节标题连起来读，应能讲通 A。
- 每页标题写判断句，内容是支撑它的论据。
- 动笔前先想清楚“读完最希望对方记住的那一句话”，那就是 A。
- 设计一个可记忆抓手（核心策略名/金句/比喻），开场、章节、结尾重复。
