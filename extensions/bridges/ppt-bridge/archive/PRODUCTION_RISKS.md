# PPT Bridge 系统风险评估与生产级改进方案

## 📊 风险清单

### 🔴 高风险（会导致服务不可用）

1. **Web Worker 加载失败没有可靠降级**
   - 问题：Worker 文件 404 时，降级到主线程心跳但可能已经太晚
   - 影响：编辑器接管失败，所有工具调用失败
   - 概率：中（浏览器安全策略、CORS、文件缺失）

2. **多个 node 进程残留导致端口冲突**
   - 问题：taskkill //F 会杀死所有 node.exe，包括无关进程
   - 影响：其他 node 服务被误杀
   - 概率：高（当前启动脚本问题）

3. **编辑器心跳停止但 MCP 工具不知道**
   - 问题：owner.age > 15s 后工具失败，但没有自动唤醒机制
   - 影响：用户需要手动刷新页面
   - 概率：高（浏览器节流）

4. **pushState 静默失败导致 deck 不同步**
   - 问题：catch 后不处理，镜像可能过期
   - 影响：截图显示旧内容，deck 丢失
   - 概率：中（网络抖动、桥重启）

### 🟡 中风险（影响用户体验）

5. **浏览器缓存导致旧版 JS 残留**
   - 问题：手动 Ctrl+Shift+R 才能更新
   - 影响：新功能无法使用，bug 修复不生效
   - 概率：高（浏览器默认行为）

6. **单实例锁文件残留**
   - 问题：进程崩溃时锁文件可能不清理
   - 影响：下次启动失败，用户困惑
   - 概率：中（异常退出）

7. **Worker 和主线程同时发心跳**
   - 问题：降级时可能出现竞争
   - 影响：claim 请求翻倍，桥压力增加
   - 概率：低（只在降级瞬间）

8. **构建产物不完整**
   - 问题：heartbeat-worker.js 需要手动复制
   - 影响：部署后 Worker 404
   - 概率：高（手动步骤）

### 🟢 低风险（边缘情况）

9. **localStorage quota 超限**
   - 问题：多窗口广播失败
   - 影响：窗口不让位，可能冲突
   - 概率：低（需要大量数据）

10. **长时间后台导致连接断开**
    - 问题：Worker 心跳成功但长轮询泵停止
    - 影响：指令不应用
    - 概率：低（需要数小时后台）
