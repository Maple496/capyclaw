# Design Token 与主题

## 先锁 token，再画任何一页

```json
{
  "accent": "#002FA7",
  "ink": "#0a0a0a",
  "paper": "#fafaf8",
  "font_sans": "system-ui / 客户 VI 字体",
  "grid": 12
}
```

- 客户有 VI：用客户主色作为唯一 accent。
- 没有 VI：从预设主题选一套，不要临时调色。
- 绝不从记忆猜品牌色；必须来自客户 VI 或明确预设。

## 单一强调色铁律

- 一份 deck 只用一套主题，全程不换 accent。
- 不混搭两个高亮色；accent 只用于关键数字/单字符/关键线条。
- 灰阶保持一致：paper / grey-1 / grey-2 / grey-3 / ink；不要用纯白纯黑替代全部灰阶。

## 预设主题

| 主题 | accent | 适合 |
|---|---|---|
| 克莱因蓝 | `#002FA7` | 通用/商业/科技，默认 |
| 柠檬黄 | `#FFD500` | 年轻/运动/零售；accent 上文字用纯黑 |
| 柠檬绿 | `#C5E803` | 生态/未来/Z 世代；accent 上文字用纯黑 |
| 安全橙 | `#FF6B35` | 工业/警示/紧迫；白字加粗 |

## 审计

确定性审计应检查：非中性色种类 > 3 → 配色漂移；渐变/阴影/大圆角 → 风格风险。
