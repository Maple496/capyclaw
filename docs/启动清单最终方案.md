## 🚀 使用方法

### 1. 生成清单

```bash
# 生成不同的清单
node scripts/generate-manifest.mjs empty        # 空清单
node scripts/generate-manifest.mjs minimal      # 最小清单
node scripts/generate-manifest.mjs development  # 开发清单
node scripts/generate-manifest.mjs production   # 生产清单
```

### 2. 使用 DSH 原生启动

```bash
# 方式1: 环境变量
DSH_MANIFEST=config/manifests/services.minimal.json npm start

# 方式2: 命令行参数
cd packages/dsh-service-broker
node server.mjs --manifest=../../config/manifests/services.minimal.json
```

### 3. DSH 自动管理一切

```
DSH 会自动：
✅ 加载清单（manifest.mjs）
✅ 启动服务（engine.mjs）
✅ 健康检查（engine.mjs）
✅ 自动重启（engine.mjs）
✅ 状态持久化（discovery.mjs）
```

**我们无需任何额外代码！**
