# dsh-scrapling 快速入门

## 📦 什么是 dsh-scrapling？

这是为 DeepSeek Harness (DSH) 创建的 Scrapling 网页抓取插件，让你在 DSH 环境中轻松使用 Scrapling 的强大功能。

## 🚀 5 分钟快速开始

### 步骤 1: 安装 Scrapling

```bash
# 安装 Python 包
pip install "scrapling[all]>=0.5"

# 安装浏览器引擎
scrapling install --force
```

### 步骤 2: 插件已就绪

插件已经在你的 DSH 项目中：
```
extensions/official/dsh-scrapling/
```

DSH 启动时会自动加载它。

### 步骤 3: 启动 DSH

```bash
cd <repo>

# 构建（如果需要）
npm run build-product

# 启动
cd apps/harness/deepseek-harness
node start-safe.mjs
```

### 步骤 4: 使用插件

在你的 DSH 插件或应用中：

```javascript
// 声明依赖
export const inject = ['scrapling']

export async function apply(ctx) {
  // 抓取网页
  const result = await ctx.scrapling.fetch('https://example.com')
  console.log('抓取到:', result.html.length, '字节')
}
```

## 💡 常见用例

### 用例 1: 简单抓取

```javascript
const page = await ctx.scrapling.fetch('https://quotes.toscrape.com/')
const doc = ctx.scrapling.parse(page.html)
const quotes = doc.css('.quote .text::text')
console.log('找到', quotes.length, '条引言')
```

### 用例 2: 动态页面（JavaScript 渲染）

```javascript
const page = await ctx.scrapling.fetchWithBrowser('https://example.com', {
  waitFor: '.content',
  timeout: 10000
})
const doc = ctx.scrapling.parse(page.html)
const content = doc.css('.content::text')
```

### 用例 3: 使用代理

```javascript
const page = await ctx.scrapling.fetch('https://example.com', {
  proxy: 'http://proxy.example.com:8080',
  headers: {
    'User-Agent': 'MyBot/1.0'
  }
})
```

## 🔧 配置选项

编辑 `cordis.patch.yml` 来自定义配置：

```yaml
- insert:
    - id: scrapling-host
      name: dsh-scrapling
      config:
        enabled: true
        defaultTimeout: 30000
        maxConcurrentRequests: 10
```

## 📚 API 速查

| 方法 | 用途 | 示例 |
|------|------|------|
| `fetch(url, opts)` | HTTP 抓取 | `await ctx.scrapling.fetch(url)` |
| `fetchWithBrowser(url, opts)` | 浏览器模式 | `await ctx.scrapling.fetchWithBrowser(url, {waitFor: '.content'})` |
| `parse(html)` | 解析 HTML | `ctx.scrapling.parse(html)` |
