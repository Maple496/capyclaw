# 反 AI Slop

这些是训练数据的“视觉最大公约数”，一眼 AI、抹掉品牌识别度——禁用：

- 紫色/多色渐变。
- emoji 当图标；用同一套线性图标或纯文字。
- 圆角卡片 + 左侧 border accent 的套路。
- 用 SVG/几何图形画人脸、插画或复杂图标。
- 满屏高亮色；强调色只占很小面积。
- 用内容填充凑数；每个元素必须挣得位置。

替代方案：

- 严格使用客户 VI 或预设 token。
- 无衬线（瑞士风）或 serif display（杂志风），一份 deck 不混。
- 直角、纯色、不透明；只允许 1px hairline 分割线。
- 极致字号对比和大幅留白。
- 真图未就位时用带标签的诚实灰块，不硬凑丑图。
