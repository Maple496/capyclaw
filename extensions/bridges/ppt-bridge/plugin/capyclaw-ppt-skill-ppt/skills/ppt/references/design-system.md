# PPTist 设计基线（按需读取）

## 画布

- 尺寸：1000 × 562.5（16:9）。
- 安全边距：左右 ≥ 56，上 ≥ 44，下 ≥ 40。
- 标题区高度：64–96；正文区从 y=140 开始。

## 字号

| 角色 | 字号 |
|---|---|
| 封面主标题 | 44–56 |
| 页面标题 | 36–44 |
| 章节过渡标题 | 40–48 |
| 正文 / 要点 | 18–22 |
| 注释 / 来源 | 11–13 |
| 大数字 | 56–72 |

一页最多一个主标题；标题不超过两行。

## 颜色

- 默认简洁路线使用内置 clean 主题色，不另造一套。
- 正文与背景对比度至少 4.5:1；深底用白字，浅底用深灰/黑。
- 强调色只占 10% 面积；不要整页高饱和。
- `ppt_recolor` 会同时处理背景、文字对比色和装饰形状，整体换色优先用它。

## 版式

| 版式 | 结构 |
|---|---|
| 封面 | 主标题 + 副标题 + 讲者/日期；可加一条装饰线 |
| 目录 | 3–6 项，纵向排列，编号对齐 |
| 章节过渡 | 大编号 + 章节标题 + 一句引导 |
| 要点页 | 标题 + 3–4 条要点；每条不超过两行 |
| 两栏 | 左文右图或左图右文；两栏间距 ≥ 32 |
| 数据页 | 1–3 个大数字 + 一行解释；数字优先 |
| 引用页 | 一句引文 + 出处；引文不超过三行 |
| 结尾 | 一句收束 + 联系方式/致谢 |

## 内容密度

- 每页一个信息点；不要把整段文字塞进一页。
- 每章 2–4 条要点；超过就拆章。
- 标题 ≤ 10 字，要点 ≤ 20 字，detail ≤ 30 字。
- 能用量化指标就不写形容词。

## 图片

- 单张主图占 40–60% 画布宽度；不要与文字抢同一块区域。
- 保持原始宽高比；`ppt_image` 会自动等比缩放。
- 图片上压字时加半透明遮罩或改用纯色块。
- 外部图片先确认来源/授权；热链可能被编辑器拦截。

## 交付检查

- 每页标题是否一眼可读？
- 是否有文字溢出/重叠/对比度不足？
- 整体版式与配色是否统一？
- 最后一页是否明确收束？
