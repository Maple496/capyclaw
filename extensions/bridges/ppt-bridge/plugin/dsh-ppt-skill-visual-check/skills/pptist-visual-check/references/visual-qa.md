# 视觉质检

## 两层

1. **确定性审计**（必跑）：越界、文字溢出、文本重叠、对比度、配色漂移、重复图片、页面密度。
2. **渲染复核**（按需）：截图看整体调性、图片比例、留白、层级与章节过渡。

## 机器检查项

- 元素是否超出画布/安全边距。
- 文本估算高度是否超过文本框。
- 文本元素是否互相重叠。
- 正文对比度 < 4.5:1 或大字 < 3:1。
- 非中性色 > 3 种。
- 同一图片重复出现。
- 单页文字过多。

## 人工检查项

- 整体调性统一，没有一页跳脱。
- 一页一观点，信息密度可读。
- 图片不变形、不重复、不模糊。
- 留白舒服，层级清晰，重点突出。
- 封面/目录/章节过渡/结尾完整。

## 输出

只输出审计结论：`pass`、`blocking`、逐页 issues、必要的截图说明。修复动作交给执行技能；本技能不改稿、不重审。
