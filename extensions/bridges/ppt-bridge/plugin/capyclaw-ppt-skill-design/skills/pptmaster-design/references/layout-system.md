# 版式系统

## 内容 → 版式

| 内容 | 版式 |
|---|---|
| 数据/数字 | 大数字 Data Hero / 矩阵 / 横向条形 |
| 流程 | 时间线 / 循环 / 系统图 |
| 对比 | 左右对照 |
| 并列判断 | 等权卡片 / 网格 |
| 结论 | 大字 statement / manifesto |

## 登记版式

正文页从登记版式选并保持骨架，不要临时发明未登记结构。内置简洁版式（封面/目录/章节/单栏要点/双栏/大数字/矩阵/时间线/引用/结尾）本身属于登记版式。

```text
封面 / 目录 / Brief 开场
章节过渡
单栏要点 / 双栏 / 大数字 / 矩阵 / 时间线
引用 / statement / 结尾行动
```

吸附网格槽位能避免黑块遮挡和元素乱叠。

## 几何与文字

- 几何图形只画线、圆、箭头、路径；可见文字放在 HTML/文本框里，绝不塞进几何图形。
- 中文大标题按字数分档限高，避免溢出；主标题:正文 ≥ 8:1。
- 12 列网格，左对齐贴近左上内容轴；除 statement 类版式外不要居中。
